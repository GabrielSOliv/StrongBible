# Android Legacy Refactoring Project

## Sobre o Projeto

Este projeto foi criado para simular um cenário real de manutenção e evolução de software legado no ecossistema Android.

A aplicação utiliza uma arquitetura baseada em **MVP (Model-View-Presenter)**, escolhida para representar projetos desenvolvidos em uma época anterior às abordagens mais modernas adotadas atualmente. O código foi estruturado de forma a reproduzir desafios comuns encontrados em aplicações que passaram por múltiplos ciclos de manutenção, como acoplamento elevado, responsabilidades mal distribuídas e limitações arquiteturais.

## Objetivo

O foco deste projeto não é apenas desenvolver funcionalidades, mas exercitar o processo contínuo de evolução de um sistema existente.

Ao longo do desenvolvimento serão realizadas atividades como:

* Correção de bugs;
* Refatoração de código;
* Implementação de novas funcionalidades;
* Redução de débito técnico;
* Aplicação de boas práticas de desenvolvimento;
* Melhoria da arquitetura;
* Aumento da testabilidade e manutenibilidade do sistema.

## Proposta

A ideia é reproduzir situações comuns do dia a dia de um desenvolvedor Android, onde raramente se inicia um projeto do zero. Em vez disso, é necessário compreender um código já existente, identificar problemas, propor melhorias e evoluir a aplicação de forma incremental sem comprometer seu funcionamento.

## Evolução Contínua

As alterações realizadas serão documentadas conforme o projeto evolui, permitindo acompanhar decisões arquiteturais, refatorações e a implementação de novos recursos ao longo do tempo.

O objetivo final é transformar gradualmente a aplicação em uma base de código mais organizada, sustentável e alinhada com práticas modernas de desenvolvimento Android.
